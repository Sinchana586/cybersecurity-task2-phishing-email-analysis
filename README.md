# Phishing Email Analysis

## Overview
This project focuses on analyzing a phishing email sample to identify common phishing indicators and understand how attackers use social engineering techniques to deceive users. The analysis includes examining the email content, sender information, suspicious URLs, and email headers.

## Objective
To identify phishing characteristics in a suspicious email sample and develop awareness of email-based cyber threats.

## Tools Used
- MXToolbox Email Header Analyzer
- VirusTotal URL Scanner
- Text Editor
- GitHub

## Files Included
- `Phishing_Email_Analysis_Report.md` – Detailed phishing email analysis report
- `sample_email.txt` – Sample phishing email used for analysis
- `screenshots/email_sample.png` – Screenshot of the phishing email sample
- `screenshots/url_analysis.png` – VirusTotal URL analysis result
- `screenshots/header_analysis.png` – MXToolbox email header analysis result

## Analysis Performed

### Email Content Analysis
The email was examined for:
- Suspicious sender address
- Generic greeting
- Urgent and threatening language
- Social engineering tactics
- Request for immediate action

### URL Analysis
The embedded URL was analyzed using VirusTotal to determine whether it was flagged as malicious and to inspect the domain structure.

### Header Analysis
The email header was analyzed using MXToolbox to identify:
- Sender information
- Return-Path details
- Sending server information
- Message-ID details
- Potential signs of email spoofing

## Phishing Indicators Identified
- Suspicious sender domain
- Urgent subject line
- Generic greeting
- Suspicious URL structure
- Unknown sending server
- Social engineering techniques
- Potential email spoofing

## Key Concepts Learned
- Phishing
- Email Spoofing
- Header Analysis
- Social Engineering
- Threat Detection
- URL Inspection

## Conclusion
The analyzed email exhibited multiple phishing characteristics, including a suspicious sender domain, urgent language, deceptive links, and signs of spoofing. The exercise helped in understanding how phishing attacks are structured and how to identify them effectively.

## Outcome
Successfully analyzed a phishing email sample and identified common phishing indicators using industry-standard tools such as VirusTotal and MXToolbox.
